# 系统设置：应用管理 实施计划

> **给执行 Agent：** 必须使用 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans` 逐 Task 执行。步骤用 `- [ ]` 勾选；每完成一步把对应 `- [ ]` 改成 `- [x]`，随该 Task 的提交一起提交。动手前先读 `AGENTS.md`。

**目标：** 在系统设置页新增「应用管理」：登记并启用各 CLI，手动指定路径，为每个 CLI 勾选允许使用的模型并选默认模型；成员表单和内置助理遵守这些配置。

**架构：** 配置存进现有 `settings` 表（每个 CLI 一条 `cli_config:<id>`）。新增后端模块 `cli_config.rs` 负责校验、读写、选择规则和三个 Tauri 命令；`cli_registry` 增加进程内的路径覆盖。前端新增纯函数库 `lib/cliConfig.ts`（可单测）、`AppManager`/`CliDetail` 两个组件，并改 `AgentForm`、`DshModelSelect`、`Settings.tsx`。

**技术栈：** Tauri 2、Rust（rusqlite、serde）、React 19、TypeScript、vitest。

**Spec：** `docs/superpowers/specs/2026-11-12-应用管理-design.md`（执行者两份一起读）。

## 全局约束

- 语言：界面文案、报错信息、代码注释、提交信息、文档一律简体中文。技术术语保留英文。
- JSON 字段：前后端之间一律 camelCase。
- 范围：只做检测登记、开关、模型白名单与默认模型。**不做**一键安装/升级，不为 Gemini/OpenCode 等写适配器，不写 Pi 适配器，不碰 M6 的运行设置，不改项目页顶部的「网络代理」「Dsh 设置」按钮。

- 不要新增依赖；函数名、类型名、字段名按本计划的 Interfaces 来，不要改。
- 不要启动任何 CLI 的执行模式。唯一允许运行的是 `grok models`，在系统临时目录里跑，只读。
- 不要推送，只在本地提交。
- 后端测试串行：`cd src-tauri && cargo test -- --test-threads=1`。若报 `frontendDist` 路径不存在，先在仓库根目录执行一次 `npm run build`。
- 分支：沿用当前 `feat/office-polish`。它包含本计划依赖的系统设置整页（`src/pages/Settings.tsx`），该页还没进 `main`。

```rust
/// 应用管理里手动指定的 CLI 程序路径。进程内共享，保存配置和启动时写入。
static PATH_OVERRIDES: Mutex<Vec<(String, PathBuf)>> = Mutex::new(Vec::new());

/// 设置或清除（传 `None`）某个 CLI 的手动路径。
pub fn set_path_override(id: &str, path: Option<PathBuf>) {
    let mut overrides = PATH_OVERRIDES.lock().unwrap_or_else(|poisoned| poisoned.into_inner());
    overrides.retain(|(key, _)| key != id);
    if let Some(path) = path { overrides.push((id.to_string(), path)); }
}

fn path_override(id: &str) -> Option<PathBuf> {
    PATH_OVERRIDES.lock().unwrap_or_else(|poisoned| poisoned.into_inner())
        .iter().find(|(key, _)| key == id).map(|(_, path)| path.clone())
}

/// 用手动指定的程序构造解析结果。PATH 前面补上程序所在目录，让 npm 垫片能找到同目录的 node。
fn resolved_from_override(id: &str, program: PathBuf, process_path: Option<OsString>) -> Option<ResolvedCli> {
    let spec = KNOWN_CLIS.iter().find(|spec| spec.id == id)?;
    if !program.is_absolute() || !program.is_file() { return None; }
    let mut dirs: Vec<PathBuf> = program.parent().map(|parent| vec![parent.to_path_buf()]).unwrap_or_default();
    if let Some(path) = &process_path { dirs.extend(std::env::split_paths(path)); }
    let path_env = std::env::join_paths(dirs).ok()?;
    Some(ResolvedCli {
        info: CliInfo {
            id: spec.id.to_string(),
            label: spec.label.to_string(),
            installed: true,
            supported: is_supported(spec.id),
            path: Some(program.to_string_lossy().into_owned()),
            version: None,
        },
        program,
        path_env,
        environment_source: EnvironmentSource::Process,
    })
}
```

在 `cli_config.rs` 文件**最前面**（测试模块之前）写入：

```rust
//! 应用管理：每个 CLI 的启用开关、手动路径、模型白名单与默认模型。
//! 配置存在 `settings` 表，键为 `cli_config:<id>`。没有记录时按默认值处理。

use std::collections::HashSet;
use std::path::{Path, PathBuf};

use rusqlite::{Connection, OptionalExtension};
use serde::{Deserialize, Serialize};

use crate::cli_registry;
use crate::error::{AppError, AppResult};

const KEY_PREFIX: &str = "cli_config:";
const MAX_MODELS: usize = 200;
const MAX_ID_LEN: usize = 512;

/// 白名单里的一个模型。`id` 对后端是不透明字符串（Dsh 的 id 是选择 JSON）。
#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
#[serde(rename_all = "camelCase")]
pub struct CliModel {
    pub id: String,
    pub label: String,
    #[serde(default)]
    pub custom: bool,
}

#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
#[serde(rename_all = "camelCase")]
pub struct CliConfig {
    pub enabled: bool,
    #[serde(default)]
    pub custom_path: Option<String>,
    /// 为空表示不限制。
    #[serde(default)]
    pub models: Vec<CliModel>,
    #[serde(default)]
    pub default_model: Option<String>,
}

fn invalid(message: impl Into<String>) -> AppError { AppError::Invalid(message.into()) }

fn label_of(id: &str) -> &str {
    cli_registry::KNOWN_CLIS.iter().find(|spec| spec.id == id).map(|spec| spec.label).unwrap_or(id)
}

fn key(id: &str) -> AppResult<String> {
    if !cli_registry::is_known(id) { return Err(invalid(format!("未知 CLI：{id}"))); }
    Ok(format!("{KEY_PREFIX}{id}"))
}

/// 没有记录时的配置：受支持的 CLI 默认启用，白名单为空。
pub fn default_config(id: &str) -> CliConfig {
    CliConfig { enabled: cli_registry::is_supported(id), custom_path: None, models: vec![], default_model: None }
}

/// 校验并整理配置。失败时不产生任何副作用。
pub fn validate(id: &str, config: &CliConfig) -> AppResult<CliConfig> {
    key(id)?;
    if config.enabled && !cli_registry::is_supported(id) {
        return Err(invalid(format!("{} 尚未接入，不能启用", label_of(id))));
    }
    if config.models.len() > MAX_MODELS { return Err(invalid(format!("每个 CLI 最多 {MAX_MODELS} 个模型"))); }
    let mut seen = HashSet::new();
    let mut models = Vec::with_capacity(config.models.len());
    for model in &config.models {
        let model_id = model.id.trim();
        if model_id.is_empty() { return Err(invalid("模型 ID 不能为空")); }
        if model_id.len() > MAX_ID_LEN || model_id.chars().any(char::is_control) {
            return Err(invalid(format!("模型 ID 无效：{}", model_id.escape_debug())));
        }
        if id == "dsh" { crate::dsh_config::parse_selection(Some(model_id))?; }
        if !seen.insert(model_id.to_string()) { return Err(invalid(format!("模型重复：{model_id}"))); }
        let label = model.label.trim();
        models.push(CliModel {
            id: model_id.to_string(),
            label: if label.is_empty() { model_id.to_string() } else { label.to_string() },
            custom: model.custom,
        });
    }
    let default_model = config.default_model.as_deref().map(str::trim).filter(|value| !value.is_empty()).map(str::to_string);
    if let Some(default) = &default_model {
        if !seen.contains(default) { return Err(invalid("默认模型必须在已勾选的模型列表中")); }
    }
    let custom_path = match config.custom_path.as_deref().map(str::trim).filter(|value| !value.is_empty()) {
        None => None,
        Some(raw) => {
            let path = Path::new(raw);
            if !path.is_absolute() || !path.is_file() { return Err(invalid(format!("指定的路径不是存在的文件：{raw}"))); }
            Some(raw.to_string())
        }
    };
    Ok(CliConfig { enabled: config.enabled, custom_path, models, default_model })
}

pub fn load(conn: &Connection, id: &str) -> AppResult<CliConfig> {
    let value: Option<String> = conn
        .query_row("SELECT value FROM settings WHERE key=?1", [key(id)?], |row| row.get(0))
        .optional()?;
    match value {
        None => Ok(default_config(id)),
        Some(value) => serde_json::from_str(&value).map_err(|_| invalid("应用配置无法读取，请重新保存")),
    }
}

/// 校验后写入，返回规范化后的配置。
pub fn save(conn: &Connection, id: &str, config: &CliConfig) -> AppResult<CliConfig> {
    let normalized = validate(id, config)?;
    let value = serde_json::to_string(&normalized).map_err(|_| invalid("无法保存应用配置"))?;
    conn.execute(
        "INSERT INTO settings(key,value) VALUES(?1,?2) ON CONFLICT(key) DO UPDATE SET value=excluded.value",
        rusqlite::params![key(id)?, value],
    )?;
    Ok(normalized)
}

pub fn is_enabled(conn: &Connection, id: &str) -> AppResult<bool> { Ok(load(conn, id)?.enabled) }

/// 新建成员、新选 CLI 时调用：已关闭的 CLI 不能再被新选。
pub fn ensure_selectable(conn: &Connection, id: &str) -> AppResult<()> {
    if is_enabled(conn, id)? { return Ok(()); }
    Err(invalid(format!("{} 已在应用管理中关闭，请先在系统设置里启用", label_of(id))))
}

/// 所有已关闭的已知 CLI（含没有适配器、默认关闭的 Pi）。
pub fn disabled_ids(conn: &Connection) -> AppResult<HashSet<String>> {
    let mut disabled = HashSet::new();
    for spec in cli_registry::KNOWN_CLIS.iter() {
        if !is_enabled(conn, spec.id)? { disabled.insert(spec.id.to_string()); }
    }
    Ok(disabled)
}

/// 成员自己填了模型就用成员的，否则用该 CLI 的默认模型。
pub fn effective_model(conn: &Connection, cli_id: &str, member_model: Option<&str>) -> AppResult<Option<String>> {
    if let Some(model) = member_model.map(str::trim).filter(|model| !model.is_empty()) {
        return Ok(Some(model.to_string()));
    }
    Ok(load(conn, cli_id)?.default_model)
}

/// 启动时把已保存的手动路径写进 `cli_registry`。读不出来的跳过，不阻止应用启动。
pub fn load_path_overrides(conn: &Connection) {
    for spec in cli_registry::KNOWN_CLIS.iter() {
        if let Ok(config) = load(conn, spec.id) {
            cli_registry::set_path_override(spec.id, config.custom_path.map(PathBuf::from));
        }
    }
}
```

```rust
/// 解析 `grok models` 的输出：取 `Available models:` 之后以 `*` 或 `-` 开头的行，第一个词是模型 ID。
pub fn parse_grok_models(output: &str) -> Vec<CliModel> {
    let mut in_list = false;
    let mut models: Vec<CliModel> = vec![];
    for line in output.lines().map(str::trim) {
        if line.eq_ignore_ascii_case("Available models:") { in_list = true; continue; }
        if !in_list { continue; }
        let Some(rest) = line.strip_prefix('*').or_else(|| line.strip_prefix('-')) else { continue; };
        let Some(id) = rest.split_whitespace().next() else { continue; };
        if models.iter().any(|model| model.id == id) { continue; }
        let label = if rest.contains("(default)") { format!("{id}（CLI 默认）") } else { id.to_string() };
        models.push(CliModel { id: id.to_string(), label, custom: false });
    }
    models
}

/// 在临时目录运行 `grok models`，带上应用的代理环境。
fn fetch_grok_models(environment: &[(String, Option<String>)]) -> Result<Vec<CliModel>, String> {
    let cli = cli_registry::resolve_cli("grok").map_err(|error| error.to_string())?;
    let (program, args) = crate::runner::platform::resolve_program(&cli.program, &["models".to_string()], Some(cli.path_env.as_os_str()))?;
    let mut command = std::process::Command::new(program);
    command.args(args).env("PATH", &cli.path_env).current_dir(std::env::temp_dir());
    for (name, value) in environment {
        match value { Some(value) => { command.env(name, value); } None => { command.env_remove(name); } }
    }
    let output = cli_registry::probe_output(command, std::time::Duration::from_secs(20))
        .ok_or_else(|| "读取 Grok 模型失败或超时，请检查登录状态与网络代理".to_string())?;
    let models = parse_grok_models(&output);
    if models.is_empty() { return Err("Grok 没有返回可用模型，请先登录后重试".into()); }
    Ok(models)
}
```

```ts
import type { CliConfig, CliConfigInput, CliModel } from "../types";

/** 列表页分组：按是否检测到安装，各组保持后端给出的顺序 */
export function groupClis(configs: CliConfig[]) {
  return { installed: configs.filter((c) => c.installed), missing: configs.filter((c) => !c.installed) };
}

/** 开关显示：未支持、未安装一律关闭且不可切换 */
export function toggleState(config: CliConfig): { checked: boolean; disabled: boolean; hint: string | null } {
  if (!config.supported) return { checked: false, disabled: true, hint: "暂未支持" };
  if (!config.installed) return { checked: false, disabled: true, hint: "未检测到，可在详情里指定路径" };
  return { checked: config.enabled, disabled: false, hint: null };
}

/** 成员表单里能选的 CLI。编辑已有成员时，当前 CLI 即使已关闭也保留 */
export function selectableClis(configs: CliConfig[], keep?: string): CliConfig[] {
  return configs.filter((c) => (c.enabled && c.installed && c.supported) || c.id === keep);
}

export function toInput(config: CliConfig, patch: Partial<CliConfigInput> = {}): CliConfigInput {
  return { enabled: config.enabled, customPath: config.customPath, models: config.models, defaultModel: config.defaultModel, ...patch };
}

export interface ModelRow extends CliModel { checked: boolean }

/** 候选列表与已勾选列表合并：候选默认不勾选，已勾选但不在候选里的（手填或候选已变）追加在后面 */
export function mergeModels(selected: CliModel[], candidates: CliModel[]): ModelRow[] {
  const rows: ModelRow[] = candidates.map((c) => ({ id: c.id, label: c.label, custom: false, checked: selected.some((s) => s.id === c.id) }));
  for (const s of selected) {
    if (!rows.some((r) => r.id === s.id)) rows.push({ ...s, checked: true });
  }
  return rows;
}

export function selectedModels(rows: ModelRow[]): CliModel[] {
  return rows.filter((r) => r.checked).map(({ id, label, custom }) => ({ id, label, custom }));
}

export function addCustomModel(rows: ModelRow[], raw: string): ModelRow[] {
  const id = raw.trim();
  if (!id) return rows;
  if (rows.some((r) => r.id === id)) return rows.map((r) => (r.id === id ? { ...r, checked: true } : r));
  return [...rows, { id, label: id, custom: true, checked: true }];
}

/** 默认模型必须是已勾选的；取消勾选后自动清空 */
export function reconcileDefault(rows: ModelRow[], current: string | null): string | null {
  return current && rows.some((r) => r.checked && r.id === current) ? current : null;
}

export interface MemberModelOptions { restricted: boolean; options: { value: string; label: string }[] }

/** 成员表单的模型选项。白名单为空不限制，沿用自由输入 */
export function memberModelOptions(config: CliConfig | undefined, saved: string): MemberModelOptions {
  if (!config || config.models.length === 0) return { restricted: false, options: [] };
  const options = config.models.map((m) => ({ value: m.id, label: m.label }));
  if (saved && !options.some((o) => o.value === saved)) options.unshift({ value: saved, label: `${saved}（不在白名单）` });
  return { restricted: true, options };
}

export function defaultModelHint(config: CliConfig | undefined): string {
  const model = config?.models.find((m) => m.id === config.defaultModel);
  return model ? `使用默认（${model.label}）` : "使用 CLI 自带默认";
}

/** Dsh 候选按白名单过滤；白名单为空不过滤；已保存的值总是保留 */
export function filterDshOptions<T extends { value: string }>(options: T[], config: CliConfig | undefined, saved: string): T[] {
  if (!config || config.models.length === 0) return options;
  const allowed = new Set(config.models.map((m) => m.id));
  return options.filter((o) => allowed.has(o.value) || o.value === saved);
}
```

```tsx
/** 系统设置 → 应用管理：列出预设 CLI，每个有开关，点进去是详情 */
export function AppManager() {
  const [configs, setConfigs] = useState<CliConfig[] | null>(null);
  const [error, setError] = useState<string | null>(null);
  const [openId, setOpenId] = useState<string | null>(null);
  const [busyId, setBusyId] = useState<string | null>(null);

  const load = useCallback(async () => {
    try { setConfigs(await api.listCliConfigs()); setError(null); }
    catch (failure) { setError(String(failure)); }
  }, []);
  useEffect(() => { void load(); }, [load]);

  function replace(saved: CliConfig) {
    setConfigs((current) => current?.map((c) => (c.id === saved.id ? saved : c)) ?? current);
  }

    try { replace(await api.saveCliConfig(config.id, toInput(config, { enabled }))); }
    catch (failure) { setError(String(failure)); }
    finally { setBusyId(null); }

  if (opened) {
    return <CliDetail config={opened} onBack={() => setOpenId(null)} onSaved={replace} onRefresh={load} />;
  }
  if (!configs) {
    return error
      ? <p role="alert" className="text-sm text-red-300">{error}</p>
      : <p className="text-sm text-slate-400">正在检测本机已安装的 CLI…</p>;

    </section>
  );
```

```tsx
  onBack: () => void;

  onSaved: (saved: CliConfig) => void;
  /** 重新检测所有 CLI */
  onRefresh: () => Promise<void>;
}

/** 单个 CLI 的详情：接入（路径、检测）与模型（勾选可用模型、选默认） */
export function CliDetail({ config, onBack, onSaved, onRefresh }: Props) {
  const [enabled, setEnabled] = useState(config.enabled);
  const [customPath, setCustomPath] = useState(config.customPath ?? "");
  const [rows, setRows] = useState<ModelRow[]>(() => mergeModels(config.models, []));
  const [defaultModel, setDefaultModel] = useState<string | null>(config.defaultModel);
  const [custom, setCustom] = useState("");
  const [loading, setLoading] = useState(false);
  const [candidateError, setCandidateError] = useState<string | null>(null);
  const [saving, setSaving] = useState(false);
  const [error, setError] = useState<string | null>(null);
  const [saved, setSaved] = useState(false);

  const loadCandidates = useCallback(async () => {
    setLoading(true); setCandidateError(null);
    try {
      let candidates: CliModel[];
      if (config.id === "dsh") {
        const settings = await api.getDshSettings();
        const catalog = await api.listDshModels(settings.profile);
        candidates = dshModelOptions(catalog, "").map((o) => ({ id: o.value, label: o.label, custom: false }));
        const failures = catalog.failures.map((f) => `${f.provider}：${f.message}`).join("；");
        if (failures) setCandidateError(failures);
      } else {
        const catalog = await api.listCliModels(config.id);
        candidates = catalog.models;
        setCandidateError(catalog.error);
      }
      setRows((current) => mergeModels(selectedModels(current), candidates));
    } catch (failure) { setCandidateError(String(failure)); }
    finally { setLoading(false); }
  }, [config.id]);
  useEffect(() => { void loadCandidates(); }, [loadCandidates]);

  const checkedRows = rows.filter((r) => r.checked);

  async function save() {
    setSaving(true); setError(null); setSaved(false);
    try {
      const next = await api.saveCliConfig(config.id, toInput(config, {
        enabled,
        customPath: customPath.trim() || null,
        models: selectedModels(rows),
        defaultModel: reconcileDefault(rows, defaultModel),
      }));
      onSaved(next);
      setDefaultModel(next.defaultModel);
      setSaved(true);
    } catch (failure) { setError(String(failure)); }
    finally { setSaving(false); }
  }

  return (
    <div className="space-y-6">
      <div className="flex items-center gap-3">
        <button type="button" className="text-sm text-slate-400 hover:text-slate-100" onClick={onBack}>← 应用管理</button>
        <h3 className="text-lg font-semibold">{config.label}</h3>
        <span className="flex-1" />
        <Switch checked={enabled && config.installed} disabled={!config.installed} label={`${config.label} 开关`} onChange={setEnabled} />
      </div>

        <h4 className="text-sm font-medium">接入</h4>
        <div className="rounded border border-slate-800 p-3 text-xs text-slate-400">
          <p>{config.installed ? `已检测到${config.version ? `，版本 ${config.version}` : ""}` : "未检测到。请先安装，或在下面手动指定可执行文件的完整路径。"}</p>
          {config.path && <p className="mt-1 break-all font-mono text-slate-500">{config.path}</p>}
        </div>
        <Field label="手动指定路径（可选，留空自动检测）">
          <input className={inputClass} value={customPath} placeholder="可执行文件的绝对路径" onChange={(event) => setCustomPath(event.target.value)} />
        </Field>
        <div className="flex gap-2">
          <Button disabled={saving} onClick={() => void onRefresh()}>重新检测</Button>
        </div>
        {config.id === "dsh" && (
          <div className="rounded border border-slate-800 p-3">
            <p className="mb-3 text-sm font-medium">Dsh 认证与配置来源</p>
            <DshSettingsPanel embedded onClose={() => undefined} onSaved={() => void loadCandidates()} />
          </div>
        )}
      </section>

      <section className="space-y-3">
        <div className="flex items-center justify-between">
          <h4 className="text-sm font-medium">模型（勾选后，成员只能从这些里选；不勾选任何一个表示不限制）</h4>
          <Button disabled={loading} onClick={() => void loadCandidates()}>{loading ? "正在读取…" : "刷新"}</Button>
        </div>
        {candidateError && <p role="alert" className="text-xs text-amber-300">{candidateError}</p>}
        {!loading && !candidateError && rows.length === 0 && (
          <p className="text-xs text-slate-500">
            {config.modelsSource === "builtin" ? "该 CLI 没有可读取的模型列表，请在下面手填模型 ID。" : "暂无可用模型。"}
          </p>
        )}
        <ul className="divide-y divide-slate-800 rounded border border-slate-800">
          {rows.map((row) => (
            <li key={row.id} className="flex items-center gap-3 px-3 py-2 text-sm">
              <input type="checkbox" aria-label={`启用 ${row.label}`} checked={row.checked}
                onChange={(event) => setRows((current) => current.map((r) => (r.id === row.id ? { ...r, checked: event.target.checked } : r)))} />
              <span className="min-w-0 flex-1 truncate" title={row.id}>{row.label}</span>
              {row.custom && <span className="shrink-0 rounded bg-slate-800 px-1.5 text-xs text-slate-400">手填</span>}
            </li>
          ))}
        </ul>
        <div className="flex gap-2">
          <input className={inputClass} value={custom} placeholder="手填模型 ID，如 my-model"
            onChange={(event) => setCustom(event.target.value)}
            onKeyDown={(event) => { if (event.key === "Enter") { setRows((c) => addCustomModel(c, custom)); setCustom(""); } }} />
          <Button className="shrink-0" disabled={custom.trim() === ""} onClick={() => { setRows((c) => addCustomModel(c, custom)); setCustom(""); }}>添加</Button>
        </div>
        <Field label="默认模型（成员没有单独指定模型时使用）">
          <select className={inputClass} value={reconcileDefault(rows, defaultModel) ?? ""} onChange={(event) => setDefaultModel(event.target.value || null)}>
            <option value="">使用 CLI 自带默认</option>
            {checkedRows.map((row) => <option key={row.id} value={row.id}>{row.label}</option>)}
          </select>
        </Field>
      </section>

      {error && <p role="alert" className="text-sm text-red-300">{error}</p>}
      {saved && <p role="status" className="text-sm text-emerald-400">已保存，从下一回合生效。</p>}
      <div className="flex justify-end gap-2">
        <Button onClick={onBack}>返回</Button>
        <Button variant="primary" disabled={saving} onClick={() => void save()}>{saving ? "正在保存…" : "保存"}</Button>
      </div>
    </div>
  );
}
```
