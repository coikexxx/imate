# M2 单 Agent 对话实施计划

> 状态：待用户确认。每个 Task 按测试先行、失败确认、实现、通过验证、单独提交的顺序执行；完成后勾选本文件对应项。

**目标：** 在项目页提供能保存消息、通过本地 Claude Code 或 Codex CLI 与单个 Agent 对话的群聊；支持 `@成员`、运行停止、人设与规章注入、助理起草规章和人设。满足 MVP 手册第 11 节 M2 验收。

**范围：** M2。只接入 Claude、Codex；不实现组长多轮讨论/派工编排（M3）、文件树/文件监听/办公室（M4）、Grok/dsh/pi（M5）、设置页与安装包（M6），也不增加用户自定义 CLI 注册配置。

**架构：** Rust/Tauri 管理 SQLite、CLI 子进程、会话和运行状态。前端通过 commands 发送请求，通过 Tauri events 接收运行状态与输出。每条消息启动一个 CLI 进程；会话由 CLI 的 session/thread ID 续接。进程流、停止、超时和进程树清理归 runner 负责。M2 是单 Agent 对话：普通消息直接交给组长处理，`@成员` 直接交给被点名成员；均为单个 Agent 执行回合，不要求或解析 M3 的组长指令 JSON、不创建协作任务。M3 再接入团队讨论和派工。

**技术栈：** 现有 Tauri 2、Rust 2024、rusqlite、serde_json、React 19、TypeScript、Vitest；新增 `tokio`（process、io-util、sync、time、macros、rt-multi-thread）、`libc`（Unix 进程组信号）、`zustand`（运行事件状态）。不引入其他依赖。

**设计依据：** `docs/MVP开发手册.md` 第 2–5、6–9、11 节；`docs/CLI实测记录.md` 的 Claude、Codex 部分；真实样本 `src-tauri/tests/fixtures/{claude,codex}/`。适配器解析只以脱敏样本为准。

**计划确认时一并确认的阶段边界：** 普通消息在 M2 只由组长作为单个 Agent 直接处理，不模拟 M3 的讨论/裁定；同项目运行期间不接收第二个回合，插话排队由 M3 实现。Codex 的真实 thread.started 没有权限回显字段，本计划建议以显式参数和对应版本的 G1 实测验证，不能伪造“已从事件核对权限”。这一点是对手册通用权限回显规则的能力差异说明，确认前不实施该例外；如要求所有 CLI 必须有运行时权限回显，则 Codex 应保持阻塞，不能静默放宽。

## 全局约束

- 只在 `feat/m2-single-agent` 分支开发；不推送。
- UI 文案、错误信息、注释和提交信息用简体中文；前后端 DTO 均使用 camelCase。
- 新增代码先写测试并确认失败，再写实现并确认通过。每个 Task 独立提交；提交时同步勾选计划步骤。
- Agent 的工作目录为已选择的项目目录。CLI 权限由适配器按 M2 实测方案设置；手册中确认执行权限可写出工作目录，UI 保留该安全提示。
- 提示词经 stdin；不把提示词放命令行。Codex 的 cwd、Claude 的 current_dir 按 M0 实测处理。
- 成功必须同时满足 CLI 完成事件和退出码 0。错误保留已经产生的回答文本，并显示明确错误；未知 JSON 行不终止进程。stderr 只保留有限尾部用于错误信息，不存令牌。
- 普通消息路由组长；显式点名但成员不存在时拒绝发送并显示错误，不静默改派。收到带 `imates` JSON 的正文时按普通 Agent 文本展示，M3 才解析指令协议。
- 重启后把数据库中残留的 running run 标成 interrupted，项目返回等待用户；不自动重跑可能已经改过文件的执行回合。
- 助理只读运行且仅返回可编辑草稿；必须由用户确认后才调用保存接口。UI 保存 draftId，后端保存与该草稿绑定的 CLI sessionId；关闭草稿时一并释放。
- 当前数据库版本 1 已有 `messages`、`runs`、`agents.session_id`、`agents.last_seen_message_id`、`settings`；本计划复用现有 schema。SQL 中存在的 session/cursor 尚未由 Agent DTO 暴露，需要补上存取函数；不改写版本 1 迁移。
- 实时运行事件使用固定 event 名称和 camelCase 载荷；UI 订阅时过滤 `projectId` / `runId` / `seq`，卸载时取消订阅。前端刷新通过只读快照恢复活动回合，后端继续执行。
- 不在仓库目录执行 CLI。真实 CLI 验收只在仓库外的新建临时项目目录进行；不保存该目录内容、用户主目录路径或凭据到仓库。
- Claude `plan` 会在其自身计划目录写文件，属于 M0 已知行为；计划提示词要求只读，但不声称该模式是强隔离。Codex resume 样本没有权限回显字段，不能显示未验证的权限保证。

## 附录 A：事件与用量契约

- `message:delta`：`{ projectId: string, runId: string, seq: number, agentId: string, text: string }`。seq 从 1 开始，在同一个 run 内递增。
- `message:new`：`{ projectId: string, runId: string | null, message: Message }`。消息以 SQLite 自增 id upsert。
- `agent:status`：`{ projectId: string, agentId: string, runId: string | null, status: "idle" | "thinking" | "talking" | "working" | "error" }`。
- `run:finished`：`{ projectId: string, runId: string, agentId: string, status: "ok" | "failed" | "timeout" | "cancelled", error: string | null }`。
- `assistant:delta`：`{ draftId: string, runId: string, seq: number, text: string }`。草稿生成事件不得进入项目群聊。
- `RuntimeSnapshot` 为活动项目只读快照：`{ projectId, runId, agentId, status, seq, partialText }`。前端挂载先订阅、再并行获取消息与快照；两者之间的事件通过 seq 去重。
- `Usage`：输入/输出/cache-read/cache-write token 都是 `Option<u64>`；费用为 `Option<f64>`，另有 `rawUsage: Value | null` 仅保存原始用量对象供累计对照。存储 JSON 用 camelCase。未上报或未确认属于本回合的值保留为 None，不假造 0；不要把 Codex cached input 再加到 input。
- 每条已知 TextDelta 同步更新 Agent 占位消息正文和 RuntimeSnapshot；Final 正文覆盖占位消息，避免重复追加 adapter 的 final result。

```rust
    conn: &Connection,
    id: &str,
    applied_persona: &str,
    seen_message_id: i64,
```

```rust
pub fn resolve_recipient<'a>(
    text: &'a str,
    agents: &'a [crate::store::agents::Agent],
) -> crate::error::AppResult<(&'a crate::store::agents::Agent, &'a str)> {
    use crate::error::AppError;
    let text = text.trim();
    if text.is_empty() { return Err(AppError::Invalid("消息不能为空".into())); }
    if let Some(mention) = text.strip_prefix('@') {
        let mut matches: Vec<_> = agents.iter().filter_map(|agent| {
            let rest = mention.strip_prefix(&agent.name)?;
            if rest.is_empty() || rest.chars().next().is_some_and(char::is_whitespace) {
                Some((agent, rest.trim()))
            } else { None }
        }).collect();
        matches.sort_by_key(|(agent, _)| std::cmp::Reverse(agent.name.len()));
        let Some((agent, prompt)) = matches.into_iter().next() else {
            return Err(AppError::Invalid("未找到被点名的成员，请从成员列表选择".into()));
        };
        if prompt.is_empty() { return Err(AppError::Invalid("点名后请填写消息内容".into())); }
        return Ok((agent, prompt));
    }
    let leader = agents.iter().find(|agent| agent.is_leader)
        .ok_or_else(|| AppError::Invalid("项目没有组长，请先配置成员".into()))?;
    Ok((leader, text))
}
```

### B7：运行注册与 command 接线（Task 7）

活动注册采用下面完整 helper；放 commands.rs，watch 的 bool 由 false 变 true 表示取消。`remove` 必须比对 runId，旧任务晚到不能清掉新回合。测试阶段先建立单元测试调用这些方法，编译确认缺失，再加实现。

```rust
#[derive(Default)]
struct ActiveRuns {
    runs: std::collections::HashMap<String, (String, tokio::sync::watch::Sender<bool>)>,
}

impl ActiveRuns {
    fn reserve(&mut self, project_id: &str, run_id: &str)
        -> crate::error::AppResult<tokio::sync::watch::Receiver<bool>> {
        if self.runs.contains_key(project_id) {
            return Err(crate::error::AppError::Invalid("项目正在运行，请先停止或等待完成".into()));
        }
        let (sender, receiver) = tokio::sync::watch::channel(false);
        self.runs.insert(project_id.into(), (run_id.into(), sender));
        Ok(receiver)
    }

    fn cancel(&self, project_id: &str) {
        if let Some((_, sender)) = self.runs.get(project_id) { let _ = sender.send(true); }
    }

    fn remove(&mut self, project_id: &str, run_id: &str) {
        if self.runs.get(project_id).is_some_and(|(active_id, _)| active_id == run_id) {
            self.runs.remove(project_id);
        }
    }
}

#[cfg(test)]
```

```ts
export interface StreamText { projectId: string; runId: string; seq: number; text: string }
export interface TextDelta { projectId: string; runId: string; seq: number; text: string }

export function applyDelta(current: StreamText, delta: TextDelta): StreamText {
  if (delta.projectId !== current.projectId || delta.runId !== current.runId) return current;
  if (delta.seq <= current.seq) return current;
  return { ...current, seq: delta.seq, text: current.text + delta.text };
}
```
