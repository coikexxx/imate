# M0 CLI 实测 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实际运行本机已装的四个 CLI（claude、codex、grok、dsh）的无头模式，录制输出样本，确定每个 CLI 的调用参数与事件格式，回填手册第 3 节的参数表。

**Architecture:** 这是一次调研，不产出应用代码。在仓库外的临时目录里按统一的五个场景跑每个 CLI，把 stdout 存成样本文件，把观察结果按固定栏目写进实测记录。样本是 M2 适配器单测的输入，实测记录是 M2 计划的依据。

**Tech Stack:** Git Bash、各 CLI 自身。

**Spec:** `docs/MVP开发手册.md` 第 3 节（CLI 适配层）、第 11 节（里程碑 M0）。

## Global Constraints

- 所有命令在 Git Bash 里执行。`dsh` 只有 `.cmd` 垫片，必须写成 `cmd //c "dsh ..."`。
- 测试目录在仓库外：`$TEMP/imates-m0`。不要在仓库目录里让 CLI 以执行模式运行。
- 提示词一律经 stdin 或文件传入，不放在命令行参数里（手册第 3 节"进程模型"）。
- 样本文件路径：`src-tauri/tests/fixtures/<cli>/<场景>.jsonl`，`<cli>` 取 `claude`、`codex`、`grok`、`dsh`。
- 样本提交前必须脱敏：不得含用户主目录的真实路径、邮箱、任何密钥或令牌。
- pi 未安装，本计划不覆盖；在实测记录里注明"顺延到 M5"。
- 实测记录用简体中文。
- 每个 CLI 的五个场景总共只调用模型 6 次左右，不要为了"多试几次"反复调用。

## 文件结构

| 文件 | 作用 |
|---|---|
| `docs/CLI实测记录.md` | 新建。每个 CLI 一节，栏目固定（见 Task 1 Step 3） |
| `src-tauri/tests/fixtures/<cli>/discuss.jsonl` | 新建。只读模式下一次带文件读取的回合 |
| `src-tauri/tests/fixtures/<cli>/execute.jsonl` | 新建。执行模式下创建一个文件的回合 |
| `src-tauri/tests/fixtures/<cli>/resume.jsonl` | 新建。续接 execute 会话的回合 |
| `src-tauri/tests/fixtures/<cli>/error.jsonl` | 新建。指定不存在的模型时的输出（stdout 与 stderr 合并） |
| `docs/MVP开发手册.md` | 修改第 3 节"各 CLI 的调用方式"表格 |

## 五个场景

所有 CLI 用同一组提示词，文件在 Task 1 里创建：

| 场景 | 提示词文件 | 模式 | 要观察什么 |
|---|---|---|---|
| discuss | `p-discuss.txt` | 只读 | 会话 ID 在哪、文本增量事件、文件读取的工具事件、结束事件、用量 |
| blocked | `p-blocked.txt` | 只读 | 只读模式是否真的拦住了写文件 |
| execute | `p-execute.txt` | 执行 | 写文件的工具事件；是否无需任何确认就完成 |
| resume | `p-resume.txt` | 只读 | 续接参数是否生效（它应当记得上一条指令） |
| escape | `p-escape.txt` | 执行 | 执行模式能否写到项目目录之外 |
| error | `p-discuss.txt` | 只读 | 模型名非法时的退出码、stdout、stderr |
