> **For agentic workers:** 计划文首的 superpowers 技能只是一种执行方式。本仓库按 `AGENTS.md` 执行：确认前不要改实现；确认后从下文分支按 Task 顺序做，先写测试并确认失败，再实现，每 Task 一次本地提交。
>
> 状态：2026-11-11 起草并执行。Task 1–7 已实现并通过自动测试，Task 8 的自动检查与文档回填已完成，真实 CLI 验收清单（Step 2）未执行，待用户在应用窗口验收。依据是同日的代码审核；同日按 M5 落地后的代码（`feat/m5-adapters`）核对过一遍。计划里的代码没有编译过，按 `AGENTS.md`「计划里的代码没有编译过」处理。

**Goal:** 把 M3 团队协作里与手册不符的九处行为改回手册的规定，让「用真实 CLI 走完一条讨论到交付」的验收有条件执行。

**Architecture:** 不加表不加列。回合构建提示词时的消息上界和人设标记写进 `runs.command` 这个已有的 JSON 字段，回合结束时据此推进游标。协议纠错和会话重建共用「同一逻辑回合最多一次自动补救」的额度，额度是否用过从 `runs` 表里上一条记录的 `error` 前缀判断，不另存状态。调度层改为整条指令期间一直占住项目和工作目录，同一批讨论回合并发启动。

**Tech Stack:** 与 M3 相同：Tauri 2、Rust edition 2024、rusqlite、tokio、React 19、TypeScript、Vitest。不新增依赖。

**Spec:** `docs/MVP开发手册.md` 第 3 节「运行期间拒绝这些修改」、第 4 节（生命周期、组长指令协议的解析规则、上下文传递、用户干预、Agent 状态、成本护栏）、第 5 节人设的存储与生效、第 7 节事件契约、第 9 节异常处理、第 11 节 M3 验收。

## Global Constraints

- 界面文案、报错、注释、提交信息使用简体中文。技术术语保留英文。
- 前后端 JSON 一律 camelCase。
- 不修改任何已发布的迁移脚本，本计划不加迁移。
- `apply_outcome`、`advance`、`TurnSpec`、`TeamSnapshot`、`build_leader_prompt`、`build_member_prompt` 的名字和字段不改。新行为加新函数。
- 自动补救的额度：同一逻辑回合里，协议纠错和会话重建合计最多一次。每次实际启动的 CLI 回合都计入单条指令的 30 回合上限。
- 执行回合不自动重试。本计划里唯一会重跑执行回合的情况是手册第 9 节允许的会话重建：启动阶段明确拒绝会话，没有任何正文和工具调用。
- 讨论成员失败时不把半截输出当成发言，只写一条系统消息说明谁没有发言和原因。
- 同一批讨论回合并发启动，但结果按批内顺序依次落库，消息顺序可预期。执行回合仍然一次一个。
- 监听和状态事件不带任何提示词、工具参数或 CLI 原始输出。
- 不做 M4、M5、M6 的内容。不动直接点名路径（`prepare_send`、`execute_project`、`finish_project`）的既有行为。
- 只本地提交，不推送。真实 CLI 不在仓库目录里以执行模式运行。

## 需要用户确认的设计点

1. **不实现「短暂调用失败自动重试一次」。** 手册第 9 节规定只对「讨论模式、无工具调用、明确可重放的短暂调用失败」重试，但现在没有任何依据能把一次失败判定为「短暂」（限流、网络、服务端故障的细分在手册第 12 节列为 MVP 之后）。本计划里自动补救只有协议纠错和会话重建两种。组长回合的其他失败仍然进入等待用户，由你点「重试」。
2. **规章全文仍然每回合都带。** 本计划只让消息不重复灌入。每回合的「冻结的项目规章」是 M3 计划为同轮快照定的做法，改它要动提示词结构和一批测试，没有纳入。它会多花 token，但不影响正确性。
3. **一次带入的未读消息最多 200 条**，超过时只带最新的 200 条，不另外提示。
4. **并行讨论期间 `get_project_runtime` 的 `active` 仍是单个快照**（返回其中最近启动的一个）。手册第 7 节说 M3 要把它扩展成集合；本计划先让前端从事件里维护正在运行的回合集合，接口形状不变。界面刷新后只能恢复出一个运行中的成员，其余成员要等下一次状态事件。
5. **本计划接管 M4 计划的 Task 5**（团队回合的实时状态与终态事件），因为它和并行讨论改的是同一段调度代码。M4 计划里的 Task 5 已改成指向这里；执行 M4 之前要先完成本计划。
6. 审核里另外三处小问题没有纳入：消息的 `sender_type` 在两条路径里分别写 `assistant` 和 `agent`；M3 通知里的规章版本串只用文件名和长度（M4 计划另加了全文摘要）；每个回合启动前都重新探测一次 CLI 版本。

```rust
/// 人设的长度加 64 位 FNV-1a。只用来比较「是不是同一版人设」。
fn persona_mark(persona: &str) -> String {
    let mut hash: u64 = 0xcbf2_9ce4_8422_2325;
    for byte in persona.as_bytes() {
        hash ^= u64::from(*byte);
        hash = hash.wrapping_mul(0x0000_0100_0000_01b3);
    }
    format!("{}:{hash:016x}", persona.len())
}

fn insert_run(conn: &Connection, agent: &Agent, mode: &str, instruction_id: &str, task_id: Option<&str>, bound: i64) -> AppResult<String> {
    let id = new_id();
    // 不记录提示词本身，只记录回合结束时要用的两项事实。
    let command = serde_json::json!({
        "source": "orchestrator", "mode": mode, "messageBound": bound, "personaMark": persona_mark(&agent.persona),
    }).to_string();
    conn.execute(
        "INSERT INTO runs (id, agent_id, mode, command, started_at, status, instruction_id, task_id) \
         VALUES (?1, ?2, ?3, ?4, ?5, 'running', ?6, ?7)",
        params![id, agent.id, mode, command, now_ms(), instruction_id, task_id],
    )?;
    Ok(id)
}
```

```rust
            Ok(RunRow {
```

```rust
/// 自动补救过的 run 用这个前缀标在 error 里。额度是否用过从上一条 run 判断，不另存状态。
const REMEDY_PREFIX: &str = "自动补救：";
const PROTOCOL_REMEDY: &str = "自动补救：协议错误：";

/// 用指定的说明结束一个 run，其余字段取自回合结果。
fn finish_run_with(conn: &Connection, run_id: &str, outcome: &RunOutcome, status: &str, error: &str) -> AppResult<()> {
    let mut noted = outcome.clone();
    noted.error = Some(error.to_string());
    finish_run(conn, run_id, &noted, status)
}

/// 这个成员在这条指令里最近一条已结束的 run 如果是一次自动补救，返回它的说明。
/// 返回 Some 表示当前这个逻辑回合的补救额度已经用掉。
fn previous_remedy(conn: &Connection, instruction_id: &str, agent_id: &str, except_run: Option<&str>) -> AppResult<Option<String>> {
    let error: Option<Option<String>> = conn.query_row(
        "SELECT error FROM runs WHERE instruction_id = ?1 AND agent_id = ?2 AND status <> 'running' \
         AND (?3 IS NULL OR id <> ?3) ORDER BY rowid DESC LIMIT 1",
        params![instruction_id, agent_id, except_run],
        |row| row.get(0),
    ).optional()?;
    Ok(error.flatten().filter(|text| text.starts_with(REMEDY_PREFIX)))
}
```

```rust
fn protocol_failed(conn: &Connection, run: &RunRow, instruction: &Instruction, agent: &Agent, outcome: &RunOutcome, reason: &str) -> AppResult<()> {
    let tx = conn.unchecked_transaction()?;
    let used = previous_remedy(&tx, &instruction.id, &agent.id, Some(&run.id))?.is_some();
    // CLI 回合本身是成功的，组长已经在会话里看过这些消息，游标照常推进。

        tx.commit()?;
        return Ok(());
    }
    finish_run_with(&tx, &run.id, outcome, "failed", &format!("协议错误：{reason}"))?;
    save_speech(&tx, instruction, agent, &outcome.final_text)?;

    messages::insert(&tx, &instruction.project_id, "system", None, "system", &notice)?;
    mark_waiting(&tx, instruction, &format!("指令协议错误：{reason}"))?;
    tx.commit()?;
    Ok(())
}
```

```rust
/// 会话在启动阶段被 CLI 明确拒绝时，清空会话并用开场加恢复包重开同一个回合，最多一次。
/// 返回 None 表示不满足条件，旧 run 原样保留，调用方照常记录结果。
pub fn rebuild_turn(conn: &Connection, run_id: &str, outcome: &RunOutcome) -> AppResult<Option<TurnSpec>> {
    let run = load_run(conn, run_id)?;
    if run.status != "running" {
        return Ok(None);
    }
    let instruction = instructions::get(conn, &run.instruction_id)?;
    if instruction.status != "running" {
        return Ok(None);
    }
    let agent = agents::get(conn, &run.agent_id)?;
    if !crate::chat::should_rebuild_session(outcome, agent.session_id.is_some(), false)
        || previous_remedy(conn, &instruction.id, &agent.id, Some(run_id))?.is_some()
    {
        return Ok(None);
    }
    let tx = conn.unchecked_transaction()?;
    // 到了回合上限时 reserve 会把指令置为等待用户；这时不重建，让调用方按普通失败记录。
    if !reserve(&tx, &instruction, 1)? {
        tx.commit()?;
        return Ok(None);
    }
    finish_run_with(&tx, run_id, outcome, "failed", &format!("{REMEDY_PREFIX}会话不可用，已清空并重开一次"))?;
    agents::set_session(&tx, &agent.id, None)?;
    let agent = agents::get(&tx, &agent.id)?;
    let (prompt, bound) = if run.mode == "execute" {
        match run.task_id.as_deref() {
            Some(task_id) => {
                let task = instructions::get_task(&tx, task_id)?;
                compose_prompt(&tx, &instruction, &agent, Stage::Execute, Some(&task), "")?
            }
            None => {
                let content = load_snapshot(&instruction.context_snapshot_json)?.mention
                    .map(|mention| mention.content).ok_or_else(|| invalid("点名内容已经不在了"))?;
                (mention_prompt(&content), message_bound(&tx, &instruction.project_id)?)
            }
        }
    } else if agent.is_leader {
        let stage = match instruction.phase.as_str() {
            "decide" => Stage::Decide,
            "review" => Stage::Review,
            "intervention" => Stage::Intervention,
            _ => Stage::Triage,
        };
        compose_prompt(&tx, &instruction, &agent, stage, None, "")?
    } else {
        let topic = match load_snapshot(&instruction.context_snapshot_json)?.pending {
            Some(StoredPending::Discuss { topic, .. }) => topic,
            None => return Err(invalid("讨论阶段缺少议题")),
        };
        compose_prompt(&tx, &instruction, &agent, Stage::Discuss, None, &topic)?
    };
    let new_run = insert_run(&tx, &agent, &run.mode, &instruction.id, run.task_id.as_deref(), bound)?;
    tx.commit()?;
    Ok(Some(spec(new_run, agent.id, &instruction.id, run.task_id, &run.mode, prompt, bound)))
}
```

`compose_prompt` 在成员没有会话时已经会带开场和恢复包（`fresh_session`、`recovery` 都取自 `agent.session_id.is_none()`），这里不用另外处理。

```rust
        let _ = wait_instruction(&conn, project_id, reason);
    }
    for spec in pending { emit_run_finished(app, project_id, spec, "failed", Some(reason.to_string())); }
}

async fn drive_team(app: tauri::AppHandle, project_id: String, mut pending: Vec<crate::orchestrator::TurnSpec>) {
    let hold = format!("hold:{project_id}");
    let cancellation = match begin_team_hold(&app, &project_id, &hold) {
        Ok(receiver) => receiver,
        Err(reason) => { park_team(&app, &project_id, &pending, &reason); return; }
    };
    loop {
        if pending.is_empty() {
            let next = {
                let state = app.state::<AppState>();
                let Ok(conn) = state.db_lock() else { break };
                let Ok(active) = crate::store::instructions::active_instruction(&conn, &project_id) else { break };
                if active.as_ref().map(|item| item.status.as_str()) != Some("running") { break; }
                crate::orchestrator::advance(&conn, &project_id)
            };
            match next {
                Ok(specs) if !specs.is_empty() => pending = specs,
                _ => break,
            }
        }
        let batch = std::mem::take(&mut pending);
        if batch.iter().any(|spec| !instruction_running(&app, &spec.instruction_id)) { break; }
        // 同一批（并行讨论）一起启动。执行和组长回合每批只有一个。
        let handles: Vec<_> = batch.iter().cloned().map(|spec| {
            let (app, project_id, hold, cancellation) = (app.clone(), project_id.clone(), hold.clone(), cancellation.clone());
            tauri::async_runtime::spawn(async move { run_with_rebuild(&app, &project_id, spec, &hold, cancellation).await })
        }).collect();
        // 结果按批内顺序依次落库，消息顺序可预期。有回合出问题也要等完其余的。
        let mut halted = false;
        for (handle, original) in handles.into_iter().zip(batch.iter()) {
            match handle.await {
                Ok((spec, StepResult::Outcome(outcome))) => {
                    let state = app.state::<AppState>();
                    let Ok(conn) = state.db_lock() else { halted = true; continue };
                    let floor = max_message_id(&conn, &project_id).unwrap_or(0);
                    let applied = crate::orchestrator::apply_outcome(&conn, &spec.run_id, &outcome);
                    emit_messages_after(&app, &conn, &project_id, &spec, floor);
                    drop(conn);
                    let error = match &applied {
                        Ok(()) => outcome.error.clone(),
                        Err(failure) => outcome.error.clone().or_else(|| Some(failure.to_string())),
                    };
                    emit_run_finished(&app, &project_id, &spec, finished_status(&outcome.status, applied.is_ok()), error);
                    if applied.is_err() { halted = true; }
                }
                Ok((spec, StepResult::NotStarted(reason))) => {
                    emit_run_finished(&app, &project_id, &spec, "failed", Some(reason));
                    halted = true;
                }
                Err(_) => {
                    let reason = "运行任务异常退出，请人工检查残留进程";
                    if let Ok(conn) = app.state::<AppState>().db_lock() {
                        let _ = crate::orchestrator::fail_launch(&conn, &original.run_id, reason);
                        let _ = wait_instruction(&conn, &project_id, reason);
                    }
                    emit_run_finished(&app, &project_id, original, "failed", Some(reason.to_string()));
                    halted = true;
                }
            }
        }
        if halted { break; }
    }
    end_team_hold(&app, &project_id, &hold);
}

/// 跑一个回合。会话在启动阶段被拒绝时重建一次再跑。
async fn run_with_rebuild(
    app: &tauri::AppHandle, project_id: &str, mut spec: crate::orchestrator::TurnSpec, hold: &str, cancellation: watch::Receiver<bool>,
) -> (crate::orchestrator::TurnSpec, StepResult) {
    loop {
        let step = run_orchestrated(app, project_id, &spec, hold, cancellation.clone()).await;
        let rebuilt = match &step {
            StepResult::Outcome(outcome) => app.state::<AppState>().db_lock().ok()
                .and_then(|conn| crate::orchestrator::rebuild_turn(&conn, &spec.run_id, outcome).ok().flatten()),
            StepResult::NotStarted(_) => None,
        };
        match rebuilt {
            // rebuild_turn 第二次一定返回 None，这个循环最多多跑一圈。
            Some(next) => {
                emit_run_finished(app, project_id, &spec, "failed", Some("旧会话不可用，已清空并重开一次".into()));
                spec = next;
            }
            None => return (spec, step),
        }
    }
}

async fn run_orchestrated(
    app: &tauri::AppHandle, project_id: &str, spec: &crate::orchestrator::TurnSpec, hold: &str, cancellation: watch::Receiver<bool>,
) -> StepResult {
    let state = app.state::<AppState>();
    // 回合没能启动：结束这次 run，指令等待用户，并让同批已经在跑的成员停下。
    // 调用它之前必须已经放开数据库锁。
    let refuse = |reason: &str| -> StepResult {
        if let Ok(conn) = state.db_lock() {
            let _ = crate::orchestrator::fail_launch(&conn, &spec.run_id, reason);
            let _ = wait_instruction(&conn, project_id, reason);
        }
        if let Ok(mut runtime) = state.runtime_lock() { runtime.cancel(project_id); }
        StepResult::NotStarted(reason.to_string())
    };
    let prepared: Result<(Agent, PathBuf), &'static str> = (|| {
        let conn = state.db_lock().map_err(|_| "数据库连接不可用")?;
        let agent = agents::get(&conn, &spec.agent_id).map_err(|_| "成员不存在")?;
        let project = projects::get(&conn, project_id).map_err(|_| "项目不存在")?;
        let folder = Path::new(&project.folder_path).canonicalize().map_err(|_| "项目目录不存在或无法读取")?;
        Ok((agent, folder))
    })();
    let (agent, folder) = match prepared {
        Ok(value) => value,
        Err(reason) => return refuse(reason),
    };
    let resolved = tauri::async_runtime::spawn_blocking({
        let cli_id = agent.cli.clone();
        move || cli_registry::resolve_cli(&cli_id)
    }).await;
    let cli = match resolved {
        Ok(Ok(cli)) => cli,
        _ => return refuse("CLI 不可用"),
    };
    let mode = if spec.mode == "discuss" { RunMode::Discuss } else { RunMode::Execute };
    let baseline = state.db_lock().ok()
        .and_then(|conn| agent.session_id.as_deref().and_then(|id| runs::latest_usage(&conn, &agent.id, id).ok().flatten()))
        .and_then(|value| serde_json::from_value(value).ok());
    // 与直接点名路径一致：带上代理环境和 Dsh 设置。它自己会拿数据库锁，调用时不能持有锁。
    let adapter = match state.make_runtime_adapter(&cli, mode, baseline) {
        Ok(adapter) => adapter,
        Err(error) => return refuse(&error.to_string()),
    };
    let request = crate::adapters::TurnRequest { prompt: spec.prompt.clone(), session_id: agent.session_id.clone(),
        cwd: folder.clone(), mode, model: agent.model.clone() };
    let run_id = spec.run_id.clone();
    let agent_id = spec.agent_id.clone();
    {
        let Ok(mut runtime) = state.runtime_lock() else { return refuse("运行状态不可用") };
        if !runtime.current(project_id, hold) {
            drop(runtime);
            return refuse("运行预留已失效");
        }
        runtime.team_started(project_id, RuntimeSnapshot { project_id: project_id.to_string(), run_id: run_id.clone(),
            agent_id: agent_id.clone(), status: "thinking".into(), seq: 0, partial_text: String::new() });
    }
    if let Ok(conn) = state.db_lock() {
        let _ = save_owner(&conn, &state.new_owner(&run_id, Some(project_id), None, &folder));
    }
    emit_events(app, vec![("agent:status", json!({"projectId": project_id, "runId": run_id, "agentId": agent_id, "status": "thinking"}))]);
    let mut shown: &'static str = "thinking";
    let outcome = crate::runner::run_turn_managed(adapter, request, cancellation, |event| {
        let next = live_status(mode, &event, shown);
        if next == shown { return; }
        shown = next;
        if let Ok(mut runtime) = app.state::<AppState>().runtime_lock() { runtime.team_status(project_id, &run_id, next); }
        emit_events(app, vec![("agent:status", json!({"projectId": project_id, "runId": run_id, "agentId": agent_id, "status": next}))]);
    }, crate::runner::RunnerConfig::default(),
        Some(state.data_dir.join("runs").join(format!("{run_id}.log"))),
        |pid| app.state::<AppState>().mark_started_under(project_id, hold, &run_id, pid)).await;
    if let Ok(mut runtime) = state.runtime_lock() { runtime.team_finished(project_id, &run_id); }
    // 两把锁分开拿，顺序与别处一致（先运行状态，后数据库），不嵌套。
    if outcome.cleanup_complete {
        if let Ok(conn) = state.db_lock() { let _ = remove_owner(&conn, &run_id); }
    } else {
        let marked = state.db_lock().ok().and_then(|conn| {
            let mut owner = load_owners(&conn).ok()?.into_iter().find(|owner| owner.run_id == run_id)?;
            owner.cleanup_required = true;
            save_owner(&conn, &owner).ok()
        }).is_some();
        if marked {
            if let Ok(mut runtime) = state.runtime_lock() { runtime.block_directory(folder, &run_id); }
        }
    }
    StepResult::Outcome(outcome)
}
```

`refuse` 闭包里会再次拿数据库锁，所以前面取成员和目录的那一段写成立即调用的闭包，保证锁在调用 `refuse` 之前已经放开。`runtime.current(...)` 那一处同理先 `drop(runtime)`。
