# GBA 风格分区办公室

## 目标与授权

2026-11-12 用户要求将办公室优化为宝可梦 GBA 时代的俯视像素风，明确划分办公区、摸鱼区、阳台、会议室和前台，并授权使用本机私密文件中的图片接口密钥进行生图。保留现有展开、缩放、拖动、实时状态与减少动态效果支持。基于已完成的 OpenOffice 版本创建 `codex/gba-office-zones`，只本地提交。

图片通过 imagegen 技能的 CLI 生成，密钥只在子进程环境中使用，不写入代码、提示词、日志或提交。接口与模型以实际目录和用户确认值为准，不静默更换模型。临时 SDK 环境不加入项目依赖。

## 布局与架构

- 32×32 网格、每格 16 逻辑像素；五个区域通过中间走廊连通。左上办公区、左下前台，右侧从上到下为会议室、摸鱼区和阳台。
- 八个固定工位沿用成员 `seatIndex`。工作与思考回办公区，发言时前往会议室的对应座位，空闲可到摸鱼区与阳台；这些都只驱动画面，不改变真实状态或调用后端。
- 地图导图、碰撞、桌椅锚点共用同一份坐标；生成图必须按导图保留墙体、门洞、桌椅和通道。
- 场景采用明亮薄荷绿、奶油色、蓝灰阴影与木地板，保留清楚像素边缘和俯视透视；中文区域牌由画布绘制，避免生成文字失真。
- 在展开视图提供五区域定位，缩略图默认展示全景；原有键盘关闭、焦点恢复和草稿保留继续生效。
