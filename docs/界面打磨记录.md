# 界面打磨记录

## 范围与方向

用户确认按 unslop 审查建议实施轻度打磨。保留现有功能、深色界面、三栏结构、办公室与文件／规章区域约 65%／35% 的比例。分支为 `feat/interface-polish`。

设计方向为沉稳、明确、有一点办公室生活感的本地团队工作台。沿用 slate / sky 色系、系统字体与现有 CLI logo；像素办公室承载主要色彩，成员列表和群聊复用工位已有的成员配色。

## 已完成

- [x] 间距：统一设置页分组节奏、常规控件 36px 和规章紧凑控件 32px；未支持 CLI 行压缩到约 48px。
- [x] 颜色：降低背景蓝色饱和度，统一主要、次要与辅助文字，空闲状态使用灰色。
- [x] 图标：保留 CLI 官方 logo，统一容器圆角；成员使用已有工位配色标记。
- [x] 文案：缩短模型标题，将白名单、默认模型和供应商查询规则放到相应说明位置；保留执行范围和配置继承提示。
- [x] 字体：设置页和首页标题采用中等字重，重要说明使用 14px，计数与版本采用等宽数字。
- [x] 布局：保留页面结构，详情操作允许换行；群聊减少整块消息底色，以间距和分隔组织发言。
- [x] 细节：按钮和输入框统一 8px 圆角，面板 12px；模型支持整行点击，默认模型有文字标记；公共交互元素有键盘焦点样式。
- [x] 视觉：保留像素办公室及其状态动画，不新增图片和依赖。
- [x] 动效：开关以 transform 移动，界面过渡约 140ms，尊重减少动态效果设置。

## 验证

- `npm test`：15 个文件、99 项测试通过。
- `npm run build`：TypeScript 检查与 Vite 构建通过。
- `git diff --check`：通过。
- 使用 ego-browser 渲染应用管理、CLI 详情和项目页并查看截图。
- 使用临时注入的后端示例数据验证模型整行勾选、保存请求、点名填入、代理分类、成员弹窗、首页卡片与新建项目表单。

上述浏览器验证没有连接真实 Tauri 后端，没有访问供应商或修改用户数据库。原生 Tauri 窗口、真实 CLI 调用和配置持久化未在本轮验收。后端代码未修改。

## 第二版：团队工作室重设计

用户查看轻度打磨版后明确授权重新设计、重构界面并保留原有交互。此授权取代首版保留深色与三栏比例的限制。分支为 `feat/studio-redesign`。

- [x] 方向：明快、有秩序、有工作室生活感；深绿导航、纸白工作区、松绿操作色。
- [x] 公共框架：新增全局导航、统一线性 SVG 图标、浅色控件与语义色；CLI logo 在浅色底上使用原图。
- [x] 首页：重新设计项目与成员总览、运行中项目计数、项目卡片与新建入口。所有计数均来自现有项目数据。
- [x] 项目页：群聊改为主工作区，文件／规章各自使用完整标签页；办公室和成员放到右侧持续显示。点名自动回到讨论。
- [x] 状态保留：群聊始终挂载，切换标签保留输入并接收事件；规章正文编辑始终挂载，切换标签保留草稿。
- [x] 设置页：顶部分类标签、应用卡片网格、紧凑未支持应用，CLI 详情采用白色配置面板和底部保存栏。
- [x] 向导：沿用三步流程，加入统一导航、步骤指示和独立表单区域。
- [x] 功能边界：未新增依赖；后端、数据库、CLI 调用和协议不变；累计用量仍待 M6。
