# 界面打磨记录

## 范围与方向

用户确认按 unslop 审查建议实施轻度打磨。保留现有功能、深色界面、三栏结构、办公室与文件／规章区域约 65%／35% 的比例。分支为 `feat/interface-polish`。

设计方向为沉稳、明确、有一点办公室生活感的本地团队工作台。沿用 slate / sky 色系、系统字体与现有 CLI logo；像素办公室承载主要色彩，成员列表和群聊复用工位已有的成员配色。

- [x] 间距：统一设置页分组节奏、常规控件 36px 和规章紧凑控件 32px；未支持 CLI 行压缩到约 48px。

## 第四次调整：GBA 五区域办公室

2026-11-12 用户要求优化为宝可梦 GBA 时代的俯视像素风，并明确区分办公区、摸鱼区、阳台、会议室和前台。用户提供本机图片接口密钥文件，并最终确认 `gpt-image-2.5-sunburst`。当晚完成场景生成，2026-11-13 完成集成与验收；分支为 `codex/gba-office-zones`，清单见 [GBA 分区办公室计划](plans/2026-11-12-GBA分区办公室.md)。

- 布局：32×32 网格、每格 16 逻辑像素，左上八工位办公区、左下前台，右上会议室、右中摸鱼区、右下阳台。中央走廊和门洞连通全部区域。区域边界、家具占地、八工位、八会议座位与八休息点共用 `src/assets/gba-office/layout.json`。
- 素材：项目先按共用坐标绘制结构参考图，使用 imagegen 技能的 CLI `edit` 模式生成背景。接口实际返回 1254×1254，最近邻规范化为 512×512、128 色无抖动 PNG，运行素材约 101 KB。完整提示词、参考图、参考图脚本和生成原图保存在 `output/imagegen/`；没有游戏原始人物、Logo 或地图。
