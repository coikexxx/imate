# GBA 分区办公室素材

2026-11-12 按用户指定的宝可梦 GBA 时代俯视像素风创作，布局为办公区、摸鱼区、阳台、会议室与前台。场景没有使用游戏原图、角色、Logo 或游戏名称贴图。

- `layout.json` 是桌椅锚点、区域边界、门洞和碰撞占地的唯一来源，前端地图与结构参考图共用。
- `background.png` 是随应用离线打包的 512×512、128 色背景。通过最近邻缩放和无抖动调色板转换，保持逻辑像素清晰。
- 背景使用用户确认的 `gpt-image-2.5-sunburst`，通过 imagegen 技能的 CLI `edit` 流程生成；输入为本项目自行绘制的结构参考图。请求 1024×1024，接口实际返回 1254×1254，再规范化为运行尺寸。
- 原始输出、完整最终提示词、参考图和可复现的参考图构建脚本保存在 `output/imagegen/`。密钥及私密接口配置不保存在本项目。
- 人物由 `src/office/gbaCharacters.ts` 绘制原创 16×24 像素帧，沿用 16×32 帧格与三方向、七列的调用接口，向左使用镜像。

旧版 OpenOffice 资源及 MIT 声明已于 2026-11-13 清理，不再保留在仓库中；当前画布只加载 GBA 素材。
